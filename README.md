# SplitSimple

SplitSimple is a lightweight household expense-sharing application for two people.

Users can record shared expenses, split costs, track balances, and record settlements.

## Planned Features

- User registration and authentication
- Household creation
- Household invitations
- Expense tracking
- 50/50 splits
- Percentage splits
- Custom amount splits
- Balance calculation
- Expense history
- Expense editing and deletion
- Settlements
- Monthly spending chart
